# 🧠 What Is AI Resume Studio?

**AI Resume Studio** is an AI-powered career assistant designed to help candidates improve their job application process.

The application uses **Google Gemini AI** to generate professional resume summaries, create personalized cover letters, analyze job descriptions, and provide ATS compatibility insights.

Instead of manually preparing every part of a job application, users can provide their profile information and let AI assist with:

```text
              ┌─────────────────────┐
              │ CANDIDATE DETAILS   │
              └──────────┬──────────┘
                         ↓
              ┌─────────────────────┐
              │ SKILLS & EXPERIENCE │
              └──────────┬──────────┘
                         ↓
              ┌─────────────────────┐
              │   GOOGLE GEMINI AI  │
              └──────────┬──────────┘
                         ↓
        ┌────────────────┼────────────────┐
        ↓                ↓                ↓
   RESUME SUMMARY   COVER LETTER     ATS ANALYSIS
        │                │                │
        └────────────────┼────────────────┘
                         ↓
              ┌─────────────────────┐
              │ CAREER INSIGHTS     │
              └──────────┬──────────┘
                         ↓
              ┌─────────────────────┐
              │ EXPORT & DOWNLOAD   │
              └─────────────────────┘
```

# ✨ Features

## 📄 01 — AI Resume Generator

Generate professional and ATS-friendly resume summaries based on:

* Skills
* Education
* Experience
* Career information

The generated content is designed to provide a strong professional summary for job applications.

---

## 💌 02 — AI Cover Letter Generator

Create personalized cover letters based on the candidate's profile and target job role.

The AI helps transform basic candidate information into a structured and professional cover letter.

---

## 🎯 03 — ATS Score Analysis

Analyze your profile against a target job description.

The application provides an AI-generated ATS compatibility score along with recommendations.

```text
           ATS ANALYSIS

              ┌───────┐
              │  87%  │
              └───────┘

        ATS Compatibility

        ✓ Relevant Skills
        ✓ Job Keywords
        ⚠ Missing Skills
        ⚠ Improvements
```

---

## 📊 04 — Career Insights

The application provides useful insights including:

* 🔎 Missing Skills
* 💪 Key Strengths
* 📈 Improvement Suggestions
* 🎯 ATS Optimization Tips

This helps candidates understand what they can improve before applying for a position.

---

## 📥 05 — PDF Export

Generated career documents can be exported as professional PDF files.

Supported exports include:

```text
Resume / Career Content
        ↓
    PDF Document
```

and:

```text
Cover Letter
        ↓
    PDF Document
```

---

## 📑 06 — ATS Report Export

ATS analysis and recommendations can also be downloaded as a `.txt` report for later reference.

# ⚙️ RUN LOCALLY

## 1. Clone Repository

```bash
git clone https://github.com/dhanush080607/Ai-Resume-Generator.git
```

## 2. Enter Project

```bash
cd Ai-Resume-Generator
```

## 3. Install Dependencies

```bash
pip install -r requirements.txt
```

## 4. Configure Gemini API

Create the required API configuration using your Gemini API key.

For Streamlit deployment, configure the secret as:

```toml
GEMINI_API_KEY = "YOUR_GEMINI_API_KEY"
```

⚠️ **Never commit your API key to GitHub.**

## 5. Run Application

```bash
streamlit run app.py
```
